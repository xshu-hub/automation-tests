# __TARGET_ID__ 测试约定

先阅读根目录 AGENTS.md。项目地址、环境、身份、登录态由外部提供。

- 业务用例从本项目 `fixtures/index.ts` 导入 test / expect。
- API 用例放在 tests/api，页面与完整业务流程放在 tests/web。
- 完整业务流程添加 @e2e；基础冒烟添加 @smoke。
- 不实现 MCP、SSO、Token 获取或刷新。
- 数据准备与清理使用 fixtures；每条用例使用唯一数据，创建后及时登记清理。
- 页面与接口封装只提取已经重复的业务操作。
- 修改后执行目标用例；地址、角色不明确时从外部工具获取后更新运行输入。

## 项目业务说明

由接入本项目的 Agent 根据实际业务补充。
